# Инструкция: как работать со мной в этом проекте

Простая памятка. Ничего учить не надо — просто иди по шагам.

---

## 1. Начать работу

1. Открой папку проекта:
   `C:\Users\Андрей\Desktop\accessible-content`
2. Запусти OpenCode в этой папке:
   ```bash
   opencode
   ```
3. Просто напиши задачу обычными словами.

Я сам прочитаю `AGENTS.md` и `docs/state.md` — там команды, структура и
текущее состояние. Объяснять проект заново не нужно.

---

## 2. Главное правило

> **Одна задача — один чат.**

- Новая задача → `/new` → пиши задачу.
- Вернуться к старой → `/sessions` (или `Ctrl+X`, затем `L`).

Так я отвечаю быстро и не путаюсь в старой истории.

---

## 3. Как ставить задачу

Хорошо:

- «Добавь кнопку "Скачать CSV" на страницу отчёта».
- «Почему на `not-domain.ru` белый экран? Проверь и почини».
- «Сделай тесты для проверки таблиц, потом покажи результат».

Плохо:

- «Сделай красиво» — непонятно, что именно менять.
- «Почини всё» — лучше по одной задаче.

Если я задаю уточняющий вопрос — ответь одним-двумя предложениями, и я продолжу.

---

## 4. Когда чат стал медленным

Признак: я долго отвечаю, хотя задача простая.

Что делать:

1. Напиши: **«Обнови docs/state.md»**.
2. Дождись ответа.
3. Нажми `/new` и продолжай работу.

Контекст не потеряется: он лежит в `AGENTS.md` и `docs/state.md`, а не в чате.

---

## 5. Проверить, что всё работает

Попроси меня: **«Запусти проверку»** — я выполню:

```bash
cd server
go test ./...
go vet ./...

cd ../client
bun run check
bun run test
bun run build
```

Или проверь сайт вручную:

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

Открой: <http://localhost:8080>

Должен открыться интерфейс, а `/api/health` вернуть `"status":"ok"`.

## 7. Публичный адрес сайта

Домен `not-domain.ru` пока не работает: Cloud.ru не пускает порты 80 и 443.
Поэтому сайт открывается через временный туннель, и адрес меняется.

Актуальный адрес попроси так: **«Дай ссылку на сайт»**.

Открывать лучше с телефона или другой сети: туннель иногда режет большие файлы,
и на некоторых провайдерах возможен белый экран.

Чтобы домен заработал навсегда, нужно в панели Cloud.ru открыть входящие
TCP 80 и 443. Это может сделать только владелец аккаунта.

## 9. Секреты

Ключи ИИ лежат только в `.env` и `deploy/.env`. Эти файлы не попадают в git.
Не присылай ключи в чат без необходимости — их придётся перевыпускать.

## 11. Если что-то сломалось

1. Напиши, что видишь: текст ошибки или «белый экран».
2. Скажи, где: локально `localhost:8080` или публичная ссылка.
3. Я проверю логи, сеть и конфиг.

Не перезапускай Docker и не удаляй файлы сам — сначала спроси, чтобы не потерять
работу.
