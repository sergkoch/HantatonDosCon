# Чекпоинт 1 — 23.11.2026, 16:30

## Что показать

- [ ] Репозиторий на GitHub, доступы у команды.
- [ ] `main` защищён: прямой push запрещён.
- [ ] CI запускается на PR и зелёный.
- [ ] API отвечает:

```bash
curl http://localhost:8080/api/health
```

- [ ] Интерфейс открывается и показывает форму.
- [ ] `POST /api/scans` создаёт скан.
- [ ] `GET /api/scans/{id}` отдаёт статус `done` и мок-находки.
- [ ] Задачи распределены в issues, у каждой есть ответственный.
- [ ] PDF-спайк: есть ответ «go-pdfium работает» или «идём на pdfcpu».
- [ ] Демо-сайт открывается локально.

## Что не требуется к чекпоинту

- реальный краулер;
- настоящие PDF-проверки;
- ИИ;
- PostgreSQL;
- деплой на сервер;
- презентация.

## Если что-то не готово

1. Не переносим чекпоинт.
2. Показываем, что готово.
3. Называем блокер и того, кто его разбирает.
4. Записываем решение в issue.

## Кто ведёт

Ведущего выбирает команда. Он следит за таймингом и записывает решения.

## После чекпоинта

1. Фиксируем, что делаем дальше.
2. Закрываем вопросы по стеку.
3. Идём в `tasks/day-2.md`.
