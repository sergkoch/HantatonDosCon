# Критерии готовности

## Definition of Done для задачи

- [ ] Issue закрыт через PR (`Closes #N`).
- [ ] Код собирается.
- [ ] Тесты проходят.
- [ ] Нет `TODO`, `console.log`, `any`, `@ts-ignore`.
- [ ] Нет секретов.
- [ ] Проверяющий поставил одобрение.
- [ ] CI зелёный.
- [ ] Демо-шаг записан в сценарий.

## Обязательные функции

- [x] Ввод URL и глубина.
- [x] Обход домена.
- [x] Поиск изображений, PDF и ссылок.
- [x] Проверка `alt`: нет, пустой, шаблонный.
- [x] Проверка ссылок: битые, шаблонный текст.
- [x] Проверка PDF: текстовый слой, теги, `/Alt`, `Title`, `Lang`.
  Отдельная HTML-версия не проверяется, OCR не подключён.
- [x] ИИ: `alt` соответствует картинке.
- [x] ИИ: текст ссылки соответствует цели.
- [x] Отчёт: элемент, тип, критичность, рекомендация.
- [x] Сводка: critical / warning / ok.
- [x] Экспорт CSV.
- [x] Экспорт JSON.
- [x] Демо-сайт с ошибками.

## Бонусы

- [x] Экспорт PDF.
- [x] Повторный скан и динамика.
- [x] История.
- [x] CI-гейт.
- [ ] Мониторинг по расписанию.
- [ ] Интеграция с CMS.

## Что смотрит жюри

| Критерий | Где доказательство |
| --- | --- |
| Польза | проблема, цифры, демо |
| Работоспособность | живой стенд, скан |
| Техническая глубина | краулер, PDF, ИИ |
| Качество | тесты, CI, отчёт |
| Дизайн | интерфейс, доступность |
| Презентация | сценарий, видео |

## Проверка перед защитой

- [x] Публичный HTTPS-стенд.
- [ ] Скан 10 страниц меньше 2 минут.
- [x] Три типа контента проверяются.
- [x] Отчёт скачивается (CSV, PDF, JSON).
- [ ] Свой интерфейс: 0 critical по axe.
- [x] Локальные тесты и сборка зелёные; CI — в PR.
- [x] Нет секретов и заглушек.
- [ ] Backup-видео.
- [ ] Репетиция на время.

## Что считаем победой

1. Живой продукт, а не слайды.
2. Понятная польза для человека, а не «мы использовали ИИ».
3. Честные границы: что умеем и чего не умеем.
4. Команда может объяснить каждую строчку.
