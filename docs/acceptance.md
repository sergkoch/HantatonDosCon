# Критерии готовности

## Definition of Done для задачи

- [ ] Issue закрыт через PR (`Closes #N`).
- [ ] Код собирается.
- [ ] Тесты проходят.
- [ ] Нет `TODO`, `console.log`, `any`, `@ts-ignore`.
- [ ] Нет секретов.
- [ ] Проверяющий поставил одобрение.
- [ ] CI зелёный.
- [ ] Демо-шаг записан в сценарий.

## Обязательные функции

- [ ] Ввод URL и глубина.
- [ ] Обход домена.
- [ ] Поиск изображений, PDF и ссылок.
- [ ] Проверка `alt`: нет, пустой, шаблонный.
- [ ] Проверка ссылок: битые, шаблонный текст.
- [ ] Проверка PDF: текстовый слой, теги, `/Alt`.
- [ ] ИИ: `alt` соответствует картинке.
- [ ] ИИ: текст ссылки соответствует цели.
- [ ] Отчёт: элемент, тип, критичность, рекомендация.
- [ ] Сводка: critical / warning / ok.
- [ ] Экспорт CSV.
- [ ] Демо-сайт с ошибками.

## Бонусы

- [ ] Экспорт PDF.
- [ ] Повторный скан и динамика.
- [ ] История.
- [ ] CI-гейт.
- [ ] Мониторинг по расписанию.
- [ ] Интеграция с CMS.

## Что смотрит жюри

| Критерий | Где доказательство |
| --- | --- |
| Польза | проблема, цифры, демо |
| Работоспособность | живой стенд, скан |
| Техническая глубина | краулер, PDF, ИИ |
| Качество | тесты, CI, отчёт |
| Дизайн | интерфейс, доступность |
| Презентация | сценарий, видео |

## Проверка перед защитой

- [ ] Публичный HTTPS-стенд.
- [ ] Скан 10 страниц меньше 2 минут.
- [ ] Три типа контента проверяются.
- [ ] Отчёт скачивается.
- [ ] Свой интерфейс: 0 critical по axe.
- [ ] Тесты и CI зелёные.
- [ ] Нет секретов и заглушек.
- [ ] Backup-видео.
- [ ] Репетиция на время.

## Что считаем победой

1. Живой продукт, а не слайды.
2. Понятная польза для человека, а не «мы использовали ИИ».
3. Честные границы: что умеем и чего не умеем.
4. Команда может объяснить каждую строчку.
