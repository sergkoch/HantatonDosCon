# Состояние проекта

Обновлено: 28.11.2026. **Обновляй этот файл после каждой крупной задачи** —
он загружается в контекст ИИ автоматически и заменяет длинную историю чата.

## Готово

- Каркас: Svelte 5 + Go/Gin, Docker Compose, демо-сайт с ошибками.
- Краулер: обход домена, глубина, `robots.txt`.
- Проверки: `alt`, ссылки, формы, таблицы, заголовки, язык.
- PDF: текстовый слой, теги, `/Alt`, `Title`, `Lang` (go-pdfium + pdfcpu).
  OCR не подключён: PDF без текста сразу critical.
- ИИ: текст ссылок и `alt` по картинке (OpenAI-совместимый API, vision).
- Отчёт: оценка, фильтры, покрытие, CSV, PDF, автооткрытие после скана.
- История: версии сканов, журнал, diff с предыдущей проверкой.
- Приватность истории: скан привязан к браузеру через `X-Client-ID`,
  чужие проверки и отчёты отдают `404` (миграция `00003_scan_owner`).
- Языки: русский и английский, переключатель в шапке; язык хранится в скане,
  находки и PDF-отчёт выходят на языке запуска (миграция `00004_scan_lang`).
  Находки хранятся на двух языках, PDF можно скачать на любом (меню у кнопки
  «Скачать PDF», миграция `00005_finding_translations`).
- PostgreSQL-хранилище при заданном `DATABASE_URL`.
- Безопасность: SSRF-защита, лимиты, CORS, allowlist.
- SEO: `robots.txt`, метатеги; Lighthouse 100/100/100.
- Веб: SVG-логотип (1 КБ вместо 210), CSS встроен в HTML, страницы
  `History`/`Report` грузятся лениво, статика кешируется на год, `index.html`
  без кеша. `llms.txt`, `/.well-known/ai-catalog.json`, WebMCP-аннотации форм.
- Заголовки безопасности в контейнере (`client/security-headers.conf`):
  CSP с хешем инлайн-скрипта, HSTS, XFO, XCTO, Referrer-Policy,
  Permissions-Policy, COOP/CORP. HSTS также на хосте.
- Статический каркас в `index.html`: заголовки и регионы видны без JS.
- API: лимит запросов по IP плюс общий потолок, финальная запись скана
  идёт отдельным контекстом, паника в горутине не оставляет скан в `running`.
- Отчёт: аналитика по типам контента и критериям WCAG, экспорт JSON,
  повторная проверка в один клик, CI-гейт `GET /api/scans/{id}/gate`.
- UI: компактная карточка cookie по центру, кнопка «Согласие на cookie» в
  футере, кликабельные контакты, заглушка ленивого маршрута, заголовок
  вкладки зависит от языка.
- Исправления: пустой `X-Client-ID` больше не видит чужие сканы в PostgreSQL,
  таймаут скана сохраняется как `failed`, порядок находок стабилен, пустые
  массивы находок и diff отдаются как `[]`, а не `null`.
- Ревью 28.11: все scan-эндпоинты требуют `X-Client-ID`; приватные ответы
  отдают `Cache-Control: no-store` и `Vary: X-Client-ID, X-Lang`; полный ID
  не показывается в UI (команда копируется кнопкой).
- ИИ: низкая уверенность не даёт critical; `matches`/`meaningful` учитываются;
  заполняются `TargetTitle`/`TargetText`; в отчёте видны `aiImagesChecked`,
  `aiLinksChecked` и уверенность находок.
- Лендинг: блок проблемы с цифрами, доказательство демо-сайта, бонусные
  функции и кнопка «Проверить демо-сайт»; демо опубликовано на `/demo/`.
- Diff считается только по проблемам; история защищена от гонки фильтров;
  таблицы доступны с клавиатуры; cookie-карточка ограничена по высоте.
