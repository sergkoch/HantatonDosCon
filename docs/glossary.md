# Словарь

**Доступность** — возможность пользоваться сайтом всем, включая людей с
инвалидностью.

**WCAG** — международные правила доступности. Нам важны 1.1.1 (alt), 2.4.4
(текст ссылки), 3.1.1 (язык страницы).

**Alt** — текстовое описание изображения для скринридера.

**Скринридер** — программа, которая читает сайт вслух.

**Краулер** — программа, которая обходит страницы сайта по ссылкам.

**Глубина** — на сколько ссылок вглубь идёт краулер. Глубина 1 — только
стартовая страница.

**PDF-текстовый слой** — текст внутри PDF, который можно выделить и прочитать.
Если его нет, это скан-картинка.

**Теги структуры PDF** — разметка заголовков, абзацев и картинок внутри PDF.
Нужна скринридерам.

**OCR** — распознавание текста с картинки.

**Vision-модель** — ИИ, который понимает изображения.

**API** — набор адресов, через которые интерфейс общается с сервером.

**JSON** — текстовый формат данных.

**Issue** — задача в GitHub.

**Ветка (branch)** — отдельная копия кода для задачи.

**Pull Request (PR)** — предложение влить ветку в `main`.

**Merge** — слияние ветки в `main`.

**CI** — автоматическая проверка кода после push.

**DoD** — Definition of Done, критерии готовности задачи.

**SSRF** — атака, когда сервер заставляют сходить по внутреннему адресу.
Поэтому сканер блокирует `localhost` и приватные IP.

**Rate limit** — ограничение числа запросов.

**Демо-сайт** — наш сайт с заранее известными ошибками для показа.
