# План на 7 дней

## Главное правило

К концу каждого дня в `main` есть рабочая версия. Лучше маленькая и живая, чем
большая и сломанная.

## Старт и чекпоинт

- **Старт:** 22.11.2026, 14:51.
- **Чекпоинт 1:** 23.11.2026, 16:30.
- **Подробный чек-лист:** `docs/checkpoint.md`.

К чекпоинту должно быть готово:

- [ ] репозиторий создан, доступы выданы;
- [ ] API отвечает на `/api/health`;
- [ ] интерфейс открывается;
- [ ] CI зелёный на первом PR;
- [ ] задачи распределены в issues;
- [ ] PDF-спайк: понятно, идём на `go-pdfium` или на `pdfcpu`;
- [ ] скан демо-сайта работает на моках.

После чекпоинта идём по дням 2–7.

## Как распределять задачи

Заранее никого не закрепляем — команда сама берёт задачи из `tasks/backlog.md`.

Правила:

1. Одна задача = один issue = один ответственный.
2. Ответственного пишем в issue, а не в шаблоне.
3. Если задача большая — делим на подзадачи.
4. Если задача не нравится — меняемся до старта, а не в середине.
5. Если никто не взял — задача не исчезает, она блокирует день.

Подробные задачи — в `tasks/day-1.md` … `tasks/day-7.md`.

## Ритуалы

### Утро — 10 минут

1. Что сделали вчера.
2. Что делаем сегодня.
3. Что мешает.

Ведущий стендапа меняется каждый день. Он обновляет доску и записывает блокеры.

### Вечер — 15 минут

1. Показываем то, что готово, на живом стенде.
2. Проверяем, что `main` работает.
3. Закрываем лишние PR.
4. Записываем, что переносим на завтра.

### Раз в день — 10 минут

Ревью PR. Автор не проверяет сам себя. Если замечаний нет — merge.

## Что режем, если не успеваем

1. Обход JS-сайтов.
2. Историю и повторные сканы.
3. Авторизацию и права доступа.
4. Интеграции с CMS.
5. Экспорт DOCX.
6. Сложные графики.
7. CI-гейт.

Не режем: форму, краулер, alt, ссылки, PDF-текстовый слой, отчёт, демо.

## Критерии победы

- [ ] Публичный HTTPS-стенд.
- [ ] Проверка трёх типов: изображение, PDF, ссылка.
- [ ] Понятный отчёт с критичностью и рекомендациями.
- [ ] Экспорт отчёта.
- [ ] Демо на реальном сайте с ошибками.
- [ ] Свой интерфейс проходит проверку доступности.
- [ ] Тесты и CI зелёные.
- [ ] Презентация на 7 минут и backup-видео.

## Правила

- В `main` только через PR.
- Автор не проверяет сам себя.
- PDF, ключи и сервер трогаем только с ответственным, которого выбрала команда.
- Секреты не коммитим.
- Если задача непонятна — обсуждаем в issue, а не в личке.
- Если кто-то застрял — помогаем, но не забираем задачу без его согласия.
