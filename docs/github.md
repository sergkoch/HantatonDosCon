# GitHub для команды

## Первый день

1. Прими приглашение в репозиторий.
2. Установи Git, Go и Bun.
3. Склонируй репозиторий:

```bash
git clone <ссылка>
cd accessible-content
```

4. Проверь, что всё запускается:

```bash
cd server
go mod tidy
go test ./...

cd ../client
bun install
bun run check
bun run test
```

## Чистый старт

- Репозиторий создаётся с нуля. Историю из других проектов не переносим.
- Первый коммит делает капитан команды после старта.
- В файлах нет личных логинов, почт и старых комментариев.
- Секреты — только в GitHub Secrets, не в коде.
- Даты и авторы коммитов не подделываем.

## Задача

1. Открой вкладку **Issues**.
2. Выбери задачу из `tasks/backlog.md`.
3. Назначь себя.
4. Перемести карточку в **In Progress** на доске.

## Ветка

```bash
git switch main
git pull
git switch -c task/12-scan-form
```

Ветку называем по номеру задачи.

## Коммит

```bash
git add .
git commit -m "feat: add scan form"
git push -u origin task/12-scan-form
```

## Pull Request

1. Открой PR из своей ветки в `main`.
2. Заполни шаблон.
3. Напиши `Closes #12`.
4. Попроси проверяющего.
5. Дождись зелёного CI.

## Ревью

Проверяющий смотрит:

- задачу и критерии приёмки;
- код;
- тесты;
- нет ли секретов;
- работает ли на живом стенде.

Замечания исправляются в той же ветке. После исправлений — снова проверка.

## Merge

Merge делает не автор после:

- одного одобрения;
- зелёного CI;
- отсутствия конфликтов.

После merge:

```bash
git switch main
git pull
git branch -d task/12-scan-form
```

## Конфликты

Если GitHub пишет «conflicts»:

1. Не паникуй.
2. Обнови `main`.
3. Влей `main` в свою ветку:

```bash
git switch main
git pull
git switch task/12-scan-form
git merge main
```

4. Исправь файлы, которые помечены.
5. `git add`, `git commit`, `git push`.
6. Если не получается — позови того, кто уже решал конфликты.

Не делай `git push --force`.

## Что не коммитим

- `.env` и любые ключи;
- `node_modules`;
- `dist`;
- логи;
- чужие файлы;
- большие бинарники без согласования.

## Полезные команды

```bash
git status
git log --oneline -10
git diff
git switch -c task/<номер>-<название>
git switch main
git pull
```

## Если застрял

Пиши в чат:

```
Задача: #12
Что делал: ...
Что получилось: ...
Что не получилось: ...
Текст ошибки: ...
```

Не сиди молча.
