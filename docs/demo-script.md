- [ ] Стенд открыт на ноутбуке и на телефоне.
- [ ] Используется подготовленный профиль браузера: **не инкогнито**, localStorage не очищать.
- [ ] За 10 минут до защиты прогнан скан демо-сайта этой же кнопкой «Проверить демо-сайт».
- [ ] Демо-сайт открыт: `https://not-domain.ru/demo/` или локальный `http://localhost:8090/`.
- [ ] CSV/PDF/JSON отчёт скачан.
- [ ] Backup-видео на флешке и в облаке.
- [ ] Презентация открыта, интернет не обязателен.

## Что говорить про стек

> Весь бэкенд на Go: краулер, проверки, PDF через PDFium в WebAssembly,
> ИИ через HTTP. Python не нужен. Один бинарник и один сервис — меньше точек
> отказа. OCR пока не подключён: PDF без текста сразу помечается critical.

## Новые шаги демо

1. На главной нажать «Проверить демо-сайт» — откроется отчёт без ручного ввода URL.
2. Открыть отчёт демо-скана: под таблицей показать аналитику по типам
   контента и критериям WCAG.
3. Нажать «Проверить снова» — создаётся v2, открывается diff с прошлой
   проверкой.
4. Раскрыть «CI-гейт», нажать «Скопировать команду с моим ID» и выполнить
   `curl`: на плохом скане команда завершается с ошибкой и кодом `409`.
5. Скачать JSON и показать `schemaVersion`, `scan.findings`, `scan.ai`.
6. Принять cookie, затем нажать «Согласие на cookie» в футере — карточка
   открывается снова по центру.

Если история пустая (чистый профиль) — не паниковать: нажать
«Проверить демо-сайт» и показать скан живьём.

## Если что-то упало

1. Не чини на сцене.
2. Переключись на backup-видео.
3. Скажи: «Покажу запись, стенд перегружен».
4. После защиты почини.

## Вопросы жюри

**Почему не Lighthouse?**
Он проверяет формальности: есть ли `alt`, а не соответствует ли он картинке.
Мы проверяем смысл.

**Откуда данные?**
Демо-сайт наш, реальные сайты — только с разрешения.

**Это не вредно для сайтов?**
Мы уважаем `robots.txt`, ставим лимиты и не сканируем без разрешения.

**Насколько точный ИИ?**
ИИ подсвечивает проблему и предлагает исправление, но решение остаётся за
человеком. В отчёте видно, сколько изображений и ссылок он проверил; при низкой
уверенности критичная находка не ставится.

**Можно ли использовать без ИИ?**
Да, формальные проверки работают. ИИ — усиление.

**Что дальше?**
Мониторинг по расписанию, CI-гейт, интеграция с CMS.
