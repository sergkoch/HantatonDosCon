## Что говорить про стек

> Весь бэкенд на Go: краулер, проверки, PDF через PDFium, ИИ через HTTP.
> Python не нужен. Один бинарник и один сервис — меньше точек отказа.
> OCR (Tesseract) пока не подключён: PDF без текста сразу помечается critical.

## Вопросы жюри

**Почему не Lighthouse?**
Он проверяет формальности: есть ли `alt`, а не соответствует ли он картинке.
Мы проверяем смысл.

**Откуда данные?**
Демо-сайт наш, реальные сайты — только с разрешения.

**Это не вредно для сайтов?**
Мы уважаем `robots.txt`, ставим лимиты и не сканируем без разрешения.

**Насколько точный ИИ?**
Показываем уверенность. Если низкая — «требует проверки», а не приговор.

**Можно ли использовать без ИИ?**
Да, формальные проверки работают. ИИ — усиление.

**Что дальше?**
Мониторинг по расписанию, CI-гейт, интеграция с CMS.
