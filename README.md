# Доступный контент

Сервис автоматической проверки доступности изображений, PDF-документов и ссылок
на веб-страницах.

> Это стартовый шаблон для команды. Каркас уже запускается, но проверки, PDF,
> ИИ и отчёты вы пишете сами по задачам из `tasks/`.
>
> **Старт:** 22.11.2026, 14:51. **Чекпоинт 1:** 23.11.2026, 16:30.
> Чек-лист — `docs/checkpoint.md`.

## Что проверяем

- у изображений есть осмысленный `alt`, и он совпадает с картинкой;
- ссылки работают, а их текст понятен вне контекста;
- у PDF есть текстовый слой, теги структуры и альтернативная версия;
- на странице есть язык, заголовок и правильный порядок заголовков.

## Стек

| Слой | Технология | Зачем |
| --- | --- | --- |
| Интерфейс | Svelte 5 + TypeScript + Vite | быстрый старт, мало кода |
| API | Go + Gin | один бинарник, простая параллельность |
| Краулер | Colly + goquery | обход домена, глубина, `robots.txt` |
| PDF | go-pdfium + pdfcpu | текст, теги, `/Alt`, рендер; без Python |
| OCR | Tesseract CLI | сканы без текстового слоя |
| ИИ | HTTP-клиент на Go | vision для картинок, текст для ссылок |
| БД | PostgreSQL + pgx + goose | сканы, страницы, находки |
| Отчёт | maroto + encoding/csv | PDF и CSV без сторонних сервисов |
| Деплой | Docker Compose + nginx | один сервер, без Kubernetes |

Подробнее — `docs/stack.md`.

## Быстрый старт

### API

```bash
cd server
go mod tidy
go run ./cmd/api
```

API поднимется на `http://localhost:8080`. Проверка:

```bash
curl http://localhost:8080/api/health
```

### Интерфейс

```bash
cd client
bun install
bun run dev
```

Интерфейс откроется на `http://localhost:5173`. Запросы к `/api` проксируются
на `http://localhost:8080`.

### База данных

Пока API хранит сканы в памяти. PostgreSQL понадобится, когда вы возьмёте
задачу про хранение:

```bash
docker compose -f deploy/docker-compose.yml up -d db
```

## Правила команды

1. Одна задача = один issue = одна ветка = один PR.
2. В `main` только через PR и зелёный CI.
3. Автор не проверяет сам себя.
4. Секреты не коммитим.
5. Если застрял на 15 минут — пиши в чат команды.
