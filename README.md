# Доступный контент

Сервис автоматической проверки доступности изображений, PDF-документов и ссылок
на веб-страницах.

> Сервис проверяет сайты и PDF и показывает, что мешает незрячим пользователям.
> Публичный стенд: `https://not-domain.ru`. Текущее состояние и ограничения —
> `docs/state.md`, разбор ТЗ — `docs/review.md`.

## Что проверяем

- у изображений есть осмысленный `alt`, и он совпадает с картинкой;
- ссылки работают, а их текст понятен вне контекста;
- у PDF есть текстовый слой, теги структуры, `/Alt`, `Title` и `Lang`;
- на странице есть язык, заголовок и правильный порядок заголовков.

## Стек

| Слой | Технология | Зачем |
| --- | --- | --- |
| Интерфейс | Svelte 5 + TypeScript + Vite | быстрый старт, мало кода |
| API | Go + Gin | один бинарник, простая параллельность |
| Краулер | Colly + goquery | обход домена, глубина, `robots.txt` |
| PDF | go-pdfium + pdfcpu | текст, теги, `/Alt`; без Python |
| OCR | не подключён | планы в `docs/stack.md`: PDF без текста сразу critical |
| ИИ | HTTP-клиент на Go | vision для картинок, текст для ссылок |
| БД | PostgreSQL + pgx + goose | сканы, страницы, находки |
| Отчёт | go-pdf/fpdf + encoding/csv | PDF и CSV без сторонних сервисов |
| Деплой | Docker Compose + nginx | один сервер, без Kubernetes |

Подробнее — `docs/stack.md`.

## Быстрый старт

### API

```bash
cd server
go mod tidy
go run ./cmd/api
```

API поднимется на `http://localhost:8080`. Проверка:

```bash
curl http://localhost:8080/api/health
```

### Интерфейс

```bash
cd client
bun install
bun run dev
```

Интерфейс откроется на `http://localhost:5173`. Запросы к `/api` проксируются
на `http://localhost:8080`.

### База данных

При заданном `DATABASE_URL` сканы и находки хранятся в PostgreSQL, иначе —
в памяти процесса. В Docker Compose база поднимается вместе со стеком:

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

- [x] проверка PDF: текстовый слой, теги структуры, `/Alt`, Title и Lang;
- [x] версии проверок, журнал и сравнение с предыдущей проверкой;
- [x] хранение сканов и находок в PostgreSQL (при заданном `DATABASE_URL`);
- [x] ИИ-проверка изображений (vision через DeepSeek);
- [x] деплой на публичный сервер (`https://not-domain.ru`, Let's Encrypt);
- [ ] OCR для PDF без текстового слоя (Tesseract в образе не подключён).

> **Текущее состояние:** находки считаются по реальному HTML и PDF. Каждая
> повторная проверка URL получает новую версию, а отчёт показывает, что
> добавилось и что исправлено с прошлого раза. Оценка покрывает alt, ссылки,
> подписи полей, заголовки, таблицы и PDF; контраст, клавиатура, ARIA и контент,
> который рендерится JavaScript, не проверяются — отчёт честно показывает это
> в блоке покрытия. PDF без текстового слоя сразу получает critical: OCR пока
> не подключён, и альтернативная HTML-версия тоже не проверяется.
