# День 6. Качество, доступность, деплой

## Цель

Публичный стенд, зелёные тесты, свой интерфейс без критичных ошибок,
red-team без kill-shot.

## Задачи

| ID | Что |

| T24 | Docker, nginx, домен, TLS |

## Порядок

1. Утром: стендап.
2. T24: деплой на сервер.
3. T23: axe и клавиатура.
4. T26: SSRF, лимиты, таймауты, секреты.
5. T27: документация.
6. Вечером: полный прогон на публичном стенде.

## Готово, если

- [ ] Сайт открывается по HTTPS.
- [ ] Скан работает на публичном стенде.
- [ ] `axe` не находит critical.
- [ ] Интерфейс проходится с клавиатуры.
- [ ] Сканер не ходит на `localhost` и приватные IP.
- [ ] В репозитории нет секретов.
- [ ] README и API описывают реальное поведение.
- [ ] CI зелёный.

## Не делаем сегодня

- рефакторинг ради красоты;
- смену стека;
- переписывание отчёта.
