# День 2. Сквозной сценарий на моках

## Цель

Форма → API → экран прогресса → отчёт. Пока с фальшивыми находками, но целиком.

## Задачи

| ID | Что |
| --- | --- |
| T05 | форма URL и глубины |
| T07 | схема БД и миграция |
| T08 | создание скана |
| T09 | получение скана и прогресс |
| T18 | каркас отчёта |

## Порядок

1. Утром: стендап, проверка `main`.
2. T08: `POST /api/scans` и `GET /api/scans/{id}`.
3. T05: форма и переход на прогресс.
4. T18: отчёт с моковыми находками.
5. Вечером: полный проход руками.

## Готово, если

- [ ] Ввожу URL → появляется скан.
- [ ] Вижу статус `queued` → `running` → `done`.
- [ ] Открывается отчёт с находками.
- [ ] Ошибка неверного URL видна пользователю.
- [ ] Сценарий записан в `docs/demo-script.md`.

## Не делаем сегодня

- реальный краулер;
- PDF;
- ИИ;
- PostgreSQL в проде;
- красивые графики.

## Проверка

```bash
curl -X POST http://localhost:8080/api/scans \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.ru","depth":1}'
```
