# День 3. Краулер и первые проверки

## Цель

Сервис сам обходит сайт и находит реальные изображения, PDF и ссылки.

## Задачи

| ID | Что |
| --- | --- |
| T10 | Colly: домен, глубина, `robots.txt`, лимиты |
| T11 | извлечение `img`, `a`, PDF, `title` |
| T12 | проверки `alt` |
| T13 | проверки ссылок |
| T20 | демо-сайт с ошибками |

## Порядок

1. Утром: стендап.
2. T10: краулер на одном URL.
3. T11: извлечение медиа.
4. T12 и T13: проверки `alt` и текста ссылок.
5. T20: демо-сайт.
6. Вечером: скан демо-сайта, первые реальные находки.

## Готово, если

- [ ] Скан `http://localhost:8090` находит 10+ элементов.
- [ ] Находки сохраняются в скан.
- [ ] Битые ссылки помечаются.
- [ ] Глубина 1 и 2 работают.
- [ ] `robots.txt` уважается.
- [ ] Таймаут не вешает сервис.

## Не делаем сегодня

- PDF;
- ИИ;
- идеальную точность;
- обход JS-сайтов.

## Осторожно

- Не сканируем чужие сайты без разрешения.
- Не ставим параллельность больше 4.
- Не ходим на `localhost` и приватные IP из кода — только демо-сайт.
