# День 5. Отчёт, фильтры и данные

## Цель

Отчёт удобно читать и отдавать заказчику. Демо не зависит от чужих сайтов.

## Задачи

| ID | Что |
| --- | --- |
| T19 | фильтры и CSV |
| T20 | демо-сайт с ошибками |
| T21 | тестовый набор и ground truth |
| T22 | e2e: форма → скан → отчёт |
| T18 | доводка отчёта |

## Порядок

1. Утром: стендап.
2. T19: фильтры по критичности и CSV.
3. T20: демо-сайт.
4. T21: 20 изображений, 10 PDF и 50 ссылок, разметка.
5. T22: e2e-сценарий.
6. Вечером: прогон на демо-сайте.

## Готово, если

- [ ] Фильтр «критично» показывает только critical.
- [ ] CSV открывается в Excel.
- [ ] Демо-сайт содержит 10+ ошибок.
- [ ] Тестовый набор лежит в `demo-site/`.
- [ ] E2E проходит локально.
- [ ] Отчёт понятен человеку, который не писал код.

## Не делаем сегодня

- историю;
- мониторинг;
- DOCX;
- графики;
- новые страницы.

## Проверка отчёта

Покажи отчёт человеку не из команды. Спроси:

1. Понятно, что не так?
2. Понятно, что делать?
3. Видно, насколько это критично?
