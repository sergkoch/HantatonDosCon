# День 7. Защита и заморозка

## Цель

Ничего не сломать и показать лучшее демо за 7 минут.

## Задачи

| ID | Что |
| --- | --- |
| T25 | презентация и backup-видео |
| — | репетиция по `docs/demo-script.md` |
| — | финальный деплой и проверка стенда |

## Расписание

| Время | Что |
| --- | --- |
| Утро | финальный прогон, фиксация багов |
| До обеда | заморозка фич: только исправления |
| После обеда | репетиция 1, тайминг |
| Вечер | репетиция 2, backup-видео, QR |
| Перед защитой | проверка сети, ноутбука, ссылок |

## Готово, если

- [ ] Презентация укладывается в 7 минут.
- [ ] Демо проходит без сети.
- [ ] Backup-видео записано.
- [ ] Ссылка и QR работают.
- [ ] На стенде последняя версия.
- [ ] Все знают свои слова.
- [ ] Нет незакоммиченных изменений.

## Заморозка

После заморозки:

- не мержим новые фичи;
- чиним только то, что ломает демо;
- не меняем стек;
- не переписываем тексты без необходимости;
- не трогаем сервер без ответственного за деплой.

## Если демо упало

1. Не паникуем.
2. Включаем backup-видео.
3. Говорим: «Покажу запись».
4. После защиты чиним.

## Вопросы жюри

Ответы — в `docs/demo-script.md`. Перед защитой каждый читает их вслух.
