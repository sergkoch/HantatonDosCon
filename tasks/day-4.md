# День 4. PDF, ИИ и настоящий отчёт

## Цель

Сервис понимает смысл: проверяет `alt` по картинке, текст ссылки по цели и
PDF по структуре.

## Задачи

| ID | Что |
| --- | --- |
| T14 | PDF-спайк: PDFium, текст, теги, `/Alt`, рендер |
| T15 | PDF-проверки |
| T16 | ИИ: `alt` по картинке |
| T17 | ИИ: текст ссылки и цель |
| T18 | отчёт на реальных находках |

## Порядок

1. Утром: стендап.
2. T14: показываем результат PDF-спайка.
3. Если PDFium работает — T15 подключает проверки.
4. Если нет — оставляем текстовый слой и метаданные, глубину PDF переносим.
5. T16 и T17: ИИ-клиент.
6. T18: реальные находки в отчёте.
7. Вечером: скан демо-сайта с PDF и картинками.

## Готово, если

- [ ] PDF без текстового слоя помечен критично.
- [ ] PDF без тегов помечен предупреждением.
- [ ] Картинка с `alt="image1.png"` получает вердикт «не соответствует».
- [ ] Ссылка «подробнее» получает предложение текста.
- [ ] При отсутствии ключа ИИ сервис не падает.
- [ ] В отчёте есть критичность и рекомендация.

## Не делаем сегодня

- полный PDF/UA;
- все критерии WCAG;
- авторизацию;
- историю;
- красоту ради красоты.

## Если PDFium не собирается

Не тратим весь день. Переключаемся на:

- `pdfcpu` для текстового слоя и метаданных;
- Tesseract для сканов;
- ИИ для картинок и ссылок.

Глубину PDF/UA добавляем, если останется время.
