# Проверки

## Задача

Превратить страницу в список находок с критичностью и рекомендацией.

## Изображения

| Код | Когда | Критичность |
| --- | --- | --- |
| `IMG_ALT_MISSING` | нет `alt` | critical |
| `IMG_ALT_EMPTY` | `alt=""` без `role="presentation"` | critical |
| `IMG_ALT_GENERIC` | «картинка», «фото», имя файла | warning |
| `IMG_ALT_MISMATCH` | ИИ: описание не соответствует | critical/warning |

## Ссылки

| Код | Когда | Критичность |
| --- | --- | --- |
| `LINK_TEXT_GENERIC` | «подробнее», «здесь», «ссылка» | warning |
| `LINK_TEXT_MISMATCH` | ИИ: текст не соответствует цели | warning |
| `LINK_BROKEN` | 4xx/5xx/таймаут | critical |

## Страница

| Код | Когда | Критичность |
| --- | --- | --- |
| `PAGE_NO_LANG` | нет `lang` | warning |
| `PAGE_NO_TITLE` | нет `title` | warning |
| `HEADING_ORDER` | нарушен порядок заголовков | warning |

## Оценка

Простая формула:

```
score = 100 - critical*10 - warning*3 - ok*0
```

Не меньше 0 и не больше 100. Если формулу меняете — обновите тесты и отчёт.

## Готово, если

- [ ] У каждой находки есть код, критичность, элемент и рекомендация.
- [ ] Есть тест на каждую проверку.
- [ ] Ложные срабатывания разбираются, а не игнорируются.
