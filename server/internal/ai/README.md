# ИИ

## Задача

Проверить смысл, а не формальность.

## Два запроса

### Картинка

Вход:

- изображение;
- `alt`;
- контекст страницы.

Выход:

```json
{
  "verdict": "ok",
  "reason": "На фото пандус у входа, alt описывает его точно.",
  "suggested_alt": "Пандус у входа в здание администрации",
  "confidence": 0.92
}
```

`verdict`: `ok`, `weak`, `wrong`, `missing`.

### Ссылка

Вход:

- текст ссылки;
- URL;
- заголовок и первый абзац целевой страницы.

Выход:

```json
{
  "meaningful": true,
  "matches": true,
  "reason": "Ссылка ведёт на положение о конкурсе.",
  "suggested_text": "Положение о конкурсе",
  "confidence": 0.88
}
```

## Правила

- `confidence < 0.7` → «требует проверки».
- Кэш по хэшу входа.
- 2 ретрая на 429/5xx.
- Лимит на скан.
- Без ключа сервис работает: семантика помечается «не проверено».

## Провайдер

Любой OpenAI-совместимый API с vision. Ключ и модели — в `.env`.

## Готово, если

- [ ] Картинка с `alt="image1.png"` получает `wrong`.
- [ ] Ссылка «подробнее» получает `suggested_text`.
- [ ] При таймауте скан не падает.
- [ ] Ответы кэшируются.
