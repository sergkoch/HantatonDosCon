# Отчёты

## Задача

Отдать результат человеку: PDF для руководителя, CSV для таблицы.

## Порядок

1. **CSV** — первым. Это быстро и полезно.
2. **PDF** — после. Через `maroto/v2`.
3. **JSON** — уже есть в API.

## CSV

Колонки:

```
severity,kind,title,element,recommendation,wcag
```

Кодировка UTF-8 с BOM, чтобы Excel не ломал русский.

## PDF

- Заголовок: сайт, дата, оценка.
- Сводка: critical / warning / ok.
- Таблица находок.
- Подпись: «Проверка не заменяет ручной аудит».

## Готово, если

- [ ] CSV открывается в Excel.
- [ ] PDF открывается и читается.
- [ ] В отчёте есть дата и оценка.
- [ ] Нет персональных данных.
