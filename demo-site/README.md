# Демо-сайт

Сайт с заранее известными ошибками доступности. Нужен, чтобы проверка не зависела
от чужих сайтов и сети.

## Запуск

```bash
cd demo-site
bunx serve . -l 8090
```

Открывается `http://localhost:8090`.

## Что здесь специально сломано

1. Изображение без `alt` (`photo-1.svg`).
2. Изображение с `alt="image2.png"`.
3. Ссылки «подробнее» и «здесь».
4. Битые ссылки на `assets/missing.pdf`.
5. Нарушен порядок заголовков: `h1` → `h3` → `h2`.
6. Низкий контраст текста (`.low-contrast`).
7. Поля формы без `label`.
8. Таблица без заголовков `th`.
9. Изображение с неверным `alt` для ИИ-проверки (`photo-3.png`: на картинке
   красный круг, а `alt` — «Синий квадрат»).

## Чего не хватает

- PDF с текстовым слоем;
- PDF-скан без текстового слоя;
- PDF без тегов структуры;
- HTML-версия PDF.

Добавьте файлы в `assets/` и обновите ссылки. Не коммитьте большие бинарники без
согласования.

## Проверка

1. Запустить демо-сайт.
2. Запустить наш сервис.
3. Ввести `http://localhost:8090`.
4. Убедиться, что находки совпадают со списком выше.
